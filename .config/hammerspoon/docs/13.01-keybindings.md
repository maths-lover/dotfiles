# 13.01 Keybindings

## Entering window mode

Press **`Cmd+Ctrl+Space`** to enter the sticky **window mode**. While active it
owns the keyboard, so keys are pressed **bare** (no modifiers). The mode persists
so you can chain operations; press `Esc` or `q` to leave.

Window **focus is global** (no window mode needed) — see the Global table below.
Because the modal keys only fire while the modal is active, they never clash with
nvim's `Ctrl+hjkl` splits or the terminal's Option/Meta.

## Window-mode map

| Key | Action |
|-----|--------|
| `h` / `l` / `k` / `j` | Left / right / top / bottom **half** |
| `1` / `2` / `3` | Left / center / right **third** |
| `[` / `]` | **Cycle thirds** left / right (L → C → R) |
| `4` / `6` | Left / right **two-thirds** |
| `y` / `u` / `b` / `n` | **Quarters** top-left / top-right / bottom-left / bottom-right |
| `m` | **Maximize** (fill usable frame) |
| `c` | **Center** (keep size) |
| `-` / `=` | **Shrink / grow** (5% of screen) |
| `Tab` / `Shift+Tab` | Move window to **next / previous display** |
| `r` | Reload config |
| `Esc` / `q` | Exit window mode |

## Global (outside window mode)

| Key | Action |
|-----|--------|
| `Cmd+Ctrl+h` / `j` / `k` / `l` | **Focus** window left / down / up / right (crosses displays) |
| `Cmd+Ctrl+R` | Reload config |

## Conflict note: Character Viewer

`Cmd+Ctrl+Space` is macOS's default **Emoji & Symbols (Character Viewer)**
shortcut. Binding it here shadows that system-wide. To rebind, change
`M.entryChord` in `lua/config.lua`, e.g.:

```lua
M.entryChord = { mods = { "cmd", "ctrl" }, key = "j" }
```

Save (auto-reloads). See also [17.01 Troubleshooting](17.01-troubleshooting.md).
