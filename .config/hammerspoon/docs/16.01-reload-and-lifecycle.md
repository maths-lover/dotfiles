# 16.01 Reload & lifecycle

## Auto-reload on save

`lua/reload.lua` watches the config directory and reloads Hammerspoon whenever a
`.lua` file changes. Because `~/.config/hammerspoon` is a GNU Stow **symlink**
into the repo, the watcher resolves it to the real repo path first
(`hs.fs.pathToAbsolute`) — otherwise FSEvents can miss edits made through the
symlink.

Edit any module, save, and the config reloads (you'll see the "Hammerspoon
loaded" alert).

## Manual reload

| Where | Key |
|-------|-----|
| Anywhere | `Cmd+Ctrl+R` |
| In window mode | `r` |

## Autostart

`init.lua` calls `hs.autoLaunch(true)`, which registers Hammerspoon as a login
item. This takes effect after the **first** manual launch (needed to grant
Accessibility anyway).

## Dock & menubar

- Dock icon: **hidden** — `hs.dockIcon(false)` in `init.lua`, reinforced by
  `MJShowDockIconKey false`.
- Menubar icon: **kept** (`MJShowMenuIconKey true`) for quick access to the
  console and reload.

## Installer defaults

`install.sh` writes these once, guarded by Hammerspoon being installed:

```sh
defaults write org.hammerspoon.Hammerspoon MJConfigFile "$HOME/.config/hammerspoon/init.lua"
defaults write org.hammerspoon.Hammerspoon MJShowDockIconKey -bool false
defaults write org.hammerspoon.Hammerspoon MJShowMenuIconKey -bool true
```
