# 12.01 Architecture & configuration

## Module layout

Mirrors the repo's nvim style: a small `init.lua` that sets load order, plus one
file per area under `lua/`.

| File | Responsibility |
|------|----------------|
| `init.lua` | `package.path` shim for `lua/`, lifecycle (autostart, dock/menubar, animation), module load order, startup alert |
| `lua/config.lua` | Tunables: entry chord, reload hotkey, resize step, float app list, alert timings |
| `lua/float.lua` | `isFloat(win)` — which windows are never managed (float apps + non-standard windows) |
| `lua/window.lua` | Frame operations (halves/thirds/quarters/maximize/center/grow/shrink) |
| `lua/display.lua` | Multi-display move + focus, and the screen (un)plug watcher |
| `lua/modal.lua` | The sticky "window mode" modal and its keymap |
| `lua/reload.lua` | Auto-reload pathwatcher + global manual-reload hotkey |

## Load order

`init.lua` requires modules leaf-deps-first: `config → float → window → display →
modal → reload`. Requiring `modal` binds the entry chord; requiring `display` and
`reload` starts their watchers.

## Config directory

`~/.config/hammerspoon` is a GNU Stow symlink into the repo. `hs.configdir`
resolves to it, and `init.lua` adds `lua/?.lua` to `package.path` from there.

## Tunables (`lua/config.lua`)

| Key | Default | Meaning |
|-----|---------|---------|
| `entryChord` | `Cmd+Ctrl+Space` | Enter window mode |
| `reloadHotkey` | `Cmd+Ctrl+R` | Global manual reload |
| `resizeStep` | `0.05` | Grow/shrink step (fraction of screen) |
| `floatApps` | `{ Neovide }` | App names never moved/resized |
| `alertDuration` | `0.6` | "skipped" / "no window" alerts |
| `modeAlertDuration` | `0.4` | Enter/leave window-mode alerts |
| `startupText` | `"Hammerspoon loaded"` | Shown on load and reload |

Edit `config.lua`, save (auto-reloads), or press `Cmd+Ctrl+R`.

## Design choices

- **Hand-rolled**, no Spoons or external deps — pure `hs.window` frame math.
- **Native Spaces kept** — no cross-Space automation; ops act within the current
  Space and across displays only.
- **Instant snapping** — `hs.window.animationDuration = 0`.
