# 11.01 Getting started

## Install

Hammerspoon is a declared cask, installed by the dotfiles bootstrap:

```sh
git clone <your-dotfiles-repo> ~/dotfiles
~/dotfiles/install.sh        # brew bundle installs hammerspoon; stow links the config
```

`~/.config/hammerspoon` is a symlink to `~/dotfiles/.config/hammerspoon`, so edits
to the config are edits to the repo.

To install by hand into an existing setup:

```sh
brew bundle --file ~/.config/Brewfile   # or: brew install --cask hammerspoon
cd ~/dotfiles && stow --restow .
```

## Config directory

Hammerspoon reads `~/.hammerspoon/init.lua` by default. The installer points it at
the dotfiles location instead (guarded by Hammerspoon being present):

```sh
defaults write org.hammerspoon.Hammerspoon MJConfigFile "$HOME/.config/hammerspoon/init.lua"
```

If you installed by hand, run that once, then reload Hammerspoon.

## Accessibility permission (required, manual)

Hammerspoon moves windows through the macOS Accessibility API, which **cannot** be
granted by script. On first launch macOS prompts you — or enable it at:

**System Settings > Privacy & Security > Accessibility > Hammerspoon (on).**

Without it, every window op silently does nothing.

## First launch

Open Hammerspoon once (`open -a Hammerspoon`). On this first run it:

- registers itself as a login item (`hs.autoLaunch(true)`), so it starts at login;
- hides its Dock icon and keeps the menubar icon;
- shows a "Hammerspoon loaded" alert.

Then press **`Cmd+Ctrl+Space`** to enter window mode and try `h` / `l` to snap the
focused window left / right. Press `Esc` to leave window mode.
