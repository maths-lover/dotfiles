# 15.01 Multi-display

Multi-monitor support is built in and degrades gracefully to a single display.
Screens are read live (`hs.screen.allScreens`), so plugging or unplugging a
monitor needs no restart. Implemented in `lua/display.lua`.

## Move a window between displays

| Key (in window mode) | Action |
|----------------------|--------|
| `Tab` | Move focused window to the **next** display |
| `Shift+Tab` | Move focused window to the **previous** display |

Moves wrap around the display list and keep the window's relative geometry
(`moveToScreen`). Floating / non-standard windows are skipped with an alert.

With only one display connected, this is a **no-op with a "one display" alert** —
never an error.

## Focus across displays

Arrow keys focus the nearest window in that direction, in global screen
coordinates, so focus crosses display boundaries:

| Key (in window mode) | Action |
|----------------------|--------|
| `←` / `→` | Focus window west / east |
| `↑` / `↓` | Focus window north / south |

Focusing is allowed for any window (including dialogs) — only *moving/resizing* is
guarded.

## Unplug / replug

Because screens are queried on demand, disconnecting or reconnecting a monitor is
handled automatically. A screen watcher is kept running as a hook for future
per-screen state; no manual re-cache is needed.

## Two-monitor note

On this machine (two monitors, sometimes one connected), everything works with
one screen and lights up the move/focus-across-display keys when the second is
plugged in.
